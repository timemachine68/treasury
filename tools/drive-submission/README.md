# ที่รับไฟล์งานนักเรียนเข้า Google Drive (Apps Script)

ใช้กับงานมอบหมายชนิด "📤 ไฟล์ PDF/รูป" — ไฟล์ไปอยู่ใน Drive ของโรงเรียน ไม่กินพื้นที่ Supabase

## ติดตั้ง (ทำครั้งเดียว ประมาณ 5 นาที)

1. เข้า <https://script.google.com> ด้วยบัญชี **@ndlp.go.th** → **โปรเจ็กต์ใหม่** ตั้งชื่อ `รับงานนักเรียน แนะให้แนว`
2. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจาก `Code.gs` ในโฟลเดอร์นี้ทั้งหมด
3. กดรูปเฟือง **การตั้งค่าโปรเจ็กต์** → ติ๊ก **แสดงไฟล์ Manifest "appsscript.json"** → กลับไปหน้าโค้ด เปิดไฟล์ `appsscript.json` แล้ววางเนื้อหาจาก `appsscript.json` ในโฟลเดอร์นี้ทับ
4. เลือกฟังก์ชัน `setupOnce` ที่แถบด้านบน → กด **เรียกใช้** → อนุญาตสิทธิ์ (ขึ้นหน้า "Google ยังไม่ได้ตรวจสอบแอปนี้" ให้กด ขั้นสูง → ไปที่ รับงานนักเรียน → อนุญาต) สคริปต์จะสร้างโฟลเดอร์ `งานนักเรียน (แนะให้แนว)` ใน My Drive ให้
5. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - กดทำให้ใช้งานได้ แล้วคัดลอก **URL ของเว็บแอป** (ลงท้าย `/exec`)
6. เปิด `index.html` หาบรรทัด `const DRIVE_URL = "";` วาง URL ระหว่างเครื่องหมายคำพูด แล้วอัปโหลด `index.html` ขึ้น repo แทนไฟล์เดิม
7. ทดสอบ: สร้างงานทดสอบให้ห้องที่มีบัญชีทดลอง เลือก "ไฟล์ PDF/รูป" → ส่งด้วยบัญชีนักเรียน → ครูกด "ดูรายชื่อ → เปิดงาน" ต้องเห็นไฟล์

## ดูแลระบบ

- **แก้โค้ดภายหลัง:** ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ไอคอนดินสอ → เวอร์ชัน "เวอร์ชันใหม่" (URL เดิมใช้ต่อได้)
- **โครงสร้างโฟลเดอร์:** `งานนักเรียน (แนะให้แนว) / ชื่องาน [รหัสสั้น] / ห้อง / รหัสนักเรียน / ไฟล์`
- **โฟลเดอร์เป็นส่วนตัว** ไม่ต้องแชร์ให้ใคร ครูเปิดไฟล์ผ่านหน้าเว็บ (ตรวจสิทธิ์จากบัญชีที่ล็อกอินอยู่)
- **ส่งงานใหม่:** ไฟล์เก่าลงถังขยะใน Drive อัตโนมัติ (กู้คืนได้ 30 วัน)
- **ลบงานในระบบ:** ไฟล์ใน Drive ยังอยู่ ถ้าต้องการลบให้ลบโฟลเดอร์ชื่องานนั้นใน Drive เอง
- **เปลี่ยนครูผู้ดูแล:** โอนความเป็นเจ้าของโฟลเดอร์หลักและโปรเจ็กต์ Apps Script ให้บัญชีใหม่ แล้วทำข้อ 4–6 ซ้ำด้วยบัญชีใหม่ (URL เปลี่ยน ต้องแก้ `DRIVE_URL`)
- **ข้อจำกัด:** ไฟล์ไม่เกิน 10 MB / ชนิด PDF, JPG, PNG เท่านั้น / Apps Script รับพร้อมกันได้ประมาณ 30 คำขอ ถ้าทั้งห้องกดส่งพร้อมกันหน้าเว็บจะลองส่งใหม่ให้เอง
