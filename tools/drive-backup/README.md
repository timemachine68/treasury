# สำรองไฟล์ Supabase → Google Drive

สคริปต์ Google Apps Script สำหรับคัดลอกไฟล์ทั้งหมดจาก Supabase Storage ของคลังแนะแนว
ไปเก็บสำรองไว้ใน Google Drive อัตโนมัติทุกคืน

## นี่ทำอะไร / ไม่ทำอะไร

| ทำ | ไม่ทำ |
|---|---|
| คัดลอกไฟล์จาก Supabase ไปเก็บใน Drive | ❌ ไม่แตะระบบอัปโหลดของเว็บ |
| จำลองโครงสร้างโฟลเดอร์ให้เปิดหาเองได้ | ❌ ไม่ลบไฟล์ใน Supabase |
| รันซ้ำได้ ไม่คัดลอกไฟล์เดิมซ้ำ | ❌ ไม่แตะฐานข้อมูล |
| คัดลอกใหม่ให้เมื่อไฟล์ถูกอัปทับ | ❌ ไม่ทำให้เว็บช้าลงหรือพังได้ |

**ถ้าสคริปต์นี้พังหรือหยุดทำงาน เว็บยังใช้งานได้ปกติทุกอย่าง** เพราะมันแค่อ่านไฟล์ออกมาเฉยๆ

## ⚠️ อ่านก่อนเริ่ม: เรื่องความปลอดภัย

สคริปต์ต้องใช้ **service_role key** ของ Supabase ซึ่งเป็น**กุญแจหลักที่เปิดได้ทุกอย่างในฐานข้อมูล**
(ต่างจาก anon key ที่ฝังอยู่ในหน้าเว็บ ซึ่งปลอดภัยเพราะถูกจำกัดด้วย RLS)

กฎเหล็ก 3 ข้อ:
1. เก็บ key ไว้ใน **Script Properties เท่านั้น** ห้ามพิมพ์ลงในโค้ด
2. **ห้ามแชร์โปรเจกต์ Apps Script นี้ให้ใคร** และห้ามตั้งเป็นสาธารณะ
3. **ห้าม commit key ขึ้น GitHub** เด็ดขาด

ถ้าเผลอทำ key หลุด ให้เข้า Supabase Dashboard → Settings → API → กด rotate ทันที

## วิธีติดตั้ง

### 1. สร้างโปรเจกต์ Apps Script

ไปที่ [script.google.com](https://script.google.com) → **New project** → ตั้งชื่อว่า `สำรองไฟล์คลังแนะแนว`

ลบโค้ดตัวอย่างที่มีอยู่ทิ้ง แล้ววางเนื้อหาทั้งหมดจากไฟล์ `supabase-drive-backup.gs` ลงไป → กดบันทึก

### 2. เอา service_role key มาจาก Supabase

Supabase Dashboard → เลือกโปรเจกต์ `guidance-library` → **Settings** → หน้า **API** (บางเวอร์ชันชื่อ **API Keys**)
→ คัดลอกค่าในช่อง **`service_role`** (ไม่ใช่ `anon` — ถ้าหยิบผิดตัวจะอ่านไฟล์ไม่ได้ เพราะ anon ติด RLS)

### 3. ใส่ค่าตั้งต้นใน Script Properties

ใน Apps Script: **Project Settings** (ไอคอนเฟือง) → เลื่อนลงล่างสุด → **Script Properties** → **Add script property**

| Property | Value | จำเป็นไหม |
|---|---|---|
| `SUPABASE_URL` | `https://ikkhjslmtjwrxzxvtokb.supabase.co` | ✅ ต้องใส่ |
| `SERVICE_ROLE_KEY` | key ที่คัดลอกมาจากขั้นที่ 2 | ✅ ต้องใส่ |
| `DRIVE_FOLDER_ID` | ID ของโฟลเดอร์ปลายทาง | ไม่ใส่ก็ได้ — จะสร้างโฟลเดอร์ `คลังแนะแนว-สำรองไฟล์` ให้เอง |
| `BUDGET_MINUTES` | `4.5` | ไม่ใส่ก็ได้ (ดูหมายเหตุด้านล่าง) |
| `SKIP_BUCKETS` | ชื่อ bucket ที่ไม่อยากสำรอง คั่นด้วย `,` | ไม่ใส่ก็ได้ |

> วิธีหา `DRIVE_FOLDER_ID`: เปิดโฟลเดอร์ใน Drive แล้วดู URL
> `drive.google.com/drive/folders/`**`1AbC...xyz`** ← ส่วนที่หนาคือ ID

### 4. ทดสอบก่อนว่าต่อติดไหม

เลือกฟังก์ชัน **`testConnection`** จากเมนูด้านบน → กด **Run**

ครั้งแรก Google จะขออนุญาตเข้าถึง Drive → กด Review permissions → เลือกบัญชี → Allow
(ถ้าขึ้นเตือน "Google hasn't verified this app" ให้กด **Advanced** → **Go to ... (unsafe)** — ปลอดภัยเพราะเป็นสคริปต์ที่เราเขียนเองในบัญชีตัวเอง)

ดูผลที่ **Execution log** ควรขึ้นประมาณนี้:

```
ต่อ Supabase สำเร็จ ✅ เจอ bucket: submissions, chang-phueak-docs, survey-photos, profile-photos
  • submissions: 132 ไฟล์ (48.0 MB)
  • chang-phueak-docs: 9 ไฟล์ (37.0 MB)
  ...
รวมทั้งหมด 85.2 MB
```

**`testConnection` ยังไม่คัดลอกอะไรเลย** แค่เช็คว่าต่อติดและนับไฟล์ให้ดู

### 5. ลองสำรองจริงครั้งแรก

เลือกฟังก์ชัน **`backupNow`** → กด **Run** → รอสักครู่แล้วไปเปิด Drive ดู

ไฟล์จะเรียงตามโครงสร้างแบบนี้:

```
คลังแนะแนว-สำรองไฟล์/
├── _manifest.json          ← บันทึกว่าสำรองอะไรไปแล้ว (อย่าลบ)
├── submissions/
│   └── <รหัสนักเรียน>/
│       └── งานที่ส่ง.pdf
└── chang-phueak-docs/
    └── <รหัสนักเรียน>/
        └── pp1_xxx.jpg
```

### 6. ตั้งเวลารันอัตโนมัติ

เลือกฟังก์ชัน **`installNightlyTrigger`** → กด **Run** ครั้งเดียวพอ

จะตั้งให้รันทุกคืนประมาณตี 2 โดยอัตโนมัติ (ดูได้ที่เมนู **Triggers** รูปนาฬิกา)

## หมายเหตุที่ควรรู้

**ครั้งแรกอาจต้องรันหลายรอบ**
Apps Script จำกัดเวลาทำงานต่อครั้ง (6 นาทีสำหรับบัญชีทั่วไป, 30 นาทีสำหรับ Workspace)
สคริปต์จะหยุดเองก่อนหมดเวลาแล้วจำไว้ว่าทำถึงไหน รอบถัดไปจะทำต่อจากเดิม
ถ้าไฟล์เยอะมากอาจต้องรอ 2-3 คืนกว่าจะครบรอบแรก หลังจากนั้นจะเร็วเพราะเหลือแค่ไฟล์ใหม่

ถ้าบัญชีเป็น Google Workspace ปรับ `BUDGET_MINUTES` เป็น `25` ได้ จะทำได้เยอะขึ้นต่อรอบ

**ถ้ารันแล้วพัง Google จะส่งอีเมลแจ้งเองอัตโนมัติ**
ไม่ต้องคอยนั่งเช็ค — Apps Script ส่งอีเมลหาเจ้าของสคริปต์เมื่อ trigger ทำงานล้มเหลว

**ถ้า Drive เต็ม**
สคริปต์จะหยุดพร้อมข้อความบอกชัดเจน ไม่เขียนทับหรือลบอะไร พอเคลียร์พื้นที่แล้วรอบถัดไปจะทำต่อเอง

**ไฟล์ที่ถูกอัปทับ (เช่น รูปโปรไฟล์)**
สคริปต์จะสังเกตจากวันที่แก้ไขล่าสุด แล้วคัดลอกเวอร์ชันใหม่มาแทน — ไฟล์เก่าย้ายไปถังขยะ Drive (กู้คืนได้ภายใน 30 วัน)

**ถ้าเผลอลบ `_manifest.json`**
ไม่เป็นไรค่ะ สคริปต์เช็คจากโฟลเดอร์จริงอีกชั้นก่อนคัดลอก จะไม่เกิดไฟล์ซ้ำ แค่รอบนั้นจะช้าหน่อยเพราะต้องไล่เช็คใหม่

## ถ้าอยากหยุดสำรองชั่วคราว

เมนู **Triggers** (รูปนาฬิกา) → กดจุดสามจุดข้าง trigger → **Delete trigger**
ไฟล์ที่สำรองไว้แล้วยังอยู่ครบ เปิดใหม่ได้ด้วยการรัน `installNightlyTrigger` อีกครั้ง
