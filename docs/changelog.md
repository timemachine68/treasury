### PR #55 — สีคำว่า "Congratulations!" ตามสีหัวบัตร
- ไฟล์: `congrats-card-draw.js`
- มหาวิทยาลัยที่ตั้งเป็น "สีสด" (หัวบัตรสว่าง): คำว่า Congratulations! เปลี่ยนจากทองไล่เฉดเป็น **ขาวครีม `#FFFDF5` ขอบทองบาง + เงาเข้ม** เพราะทองกลืนกับพื้นส้ม/แดง/ม่วงสด
- มหาวิทยาลัยอื่น (หัวบัตรเข้ม): ยังเป็นทองไล่เฉดเหมือนเดิม
- ฐานข้อมูล/สิทธิ์: ไม่เปลี่ยน · การ์ดที่อนุมัติแล้วไม่เด้ง

### PR #54 — ปรับสีมหาวิทยาลัย + ตั้งค่า "สีสด"
- ไฟล์: `congrats-card-draw.js`
- ตาราง `__UNI` เพิ่มช่องที่ 4 `'v'` = สีสด (หัวบัตรใช้สีจริง ไม่ทำให้เข้มลง; ฟังก์ชัน `uniVivid(d)`; ไม่ใช้เมื่อมี `d.color`)
- ลาดกระบัง (KMITL) `#E35205` + สีสด — หัวบัตรส้มเหมือนตัวย่อ
- ธุรกิจบัณฑิตย์ (DPU) `#6B2D5C` → **`#8E24AA`** ม่วงสด + สีสด (ราชมงคลพระนคร/บ้านสมเด็จฯ ยังเป็น `#6B2D5C`)
- แม่ฟ้าหลวง (MFU) `#A6192E` → **`#E4002B`** แดงสด + สีสด
- ฐานข้อมูล/สิทธิ์: ไม่เปลี่ยน
