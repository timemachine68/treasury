## 12 พ.ย. 2569 — ลงทะเบียน Open House (ไปชมงานมหาวิทยาลัย ม.6)

### เพิ่มลิงก์ประชาสัมพันธ์ต่องาน
- ไฟล์: `open-house-summary.html`, `open-house-register.html`, `supabase/migrations/20261112_open_house_events_info_links.sql`
- ตาราง `open_house_events` เพิ่มคอลัมน์ `info_links` (jsonb `[{label,url}]` สูงสุด 5 ลิงก์ ชื่อปุ่มไม่เกิน 60 ตัว ลิงก์ไม่เกิน 500 ตัว)
- ฐานข้อมูลรับเฉพาะ `http://` / `https://` (CHECK constraint กัน `javascript:` `data:` ลิงก์มีช่องว่าง ชื่อว่าง) · หน้าเว็บตรวจซ้ำและเติม `https://` ให้ถ้าลืมพิมพ์
- หน้าสรุป (ครูแนะแนว/แอดมิน): ปุ่ม "🔗 ลิงก์ (n)" ในตารางจัดการงาน เพิ่ม/ลบลิงก์ได้
- หน้าลงทะเบียน (นักเรียน): แสดงเป็นปุ่มใต้วันที่ของงานที่เลือก เปิดแท็บใหม่ (`noopener noreferrer`) แสดงเฉพาะลิงก์ http/https
- สิทธิ์: ไม่เปลี่ยน — นักเรียนอ่านได้อย่างเดียว ครูแนะแนว/แอดมินแก้ได้ (ทดสอบในฐานข้อมูลโดยจำลองสิทธิ์นักเรียน/ครูแนะแนว/แอดมิน: นักเรียนแก้ได้ 0 แถว ครูแนะแนวและแอดมินแก้ได้)

### ภาพรวมโมดูล (11–12 พ.ย. 2569)
- ไฟล์: `open-house-register.html` (นักเรียน), `open-house-summary.html` (ครู), เมนู 2 ปุ่มท้ายแถบใน `index.html`
- ตาราง: `open_house_events` (รายการงาน เปิด/ปิดรับ), `open_house_registrations` (หนึ่งแถวต่อ นักเรียน+งาน) · RLS เปิดทั้งสองตาราง · ฟังก์ชัน `is_guidance_staff()` เป็น SECURITY DEFINER และ revoke จาก PUBLIC/anon แล้ว
- นักเรียน: เลือก ไป/ไม่ไป · ถ้าไปเลือก ไปกับโรงเรียน/ไปเอง + คณะที่สนใจ · ชื่อ ห้อง เลขประจำตัวดึงจากโปรไฟล์ (ไม่แตะเลขบัตรประชาชน)
- ครู: กรองตามงาน/ห้อง/คณะ/ความสนใจ/การเดินทาง · ส่งออก CSV (UTF-8 BOM) · เพิ่มงานใหม่ · เปิด/ปิดรับ
- แก้บั๊ก: หน้าลงทะเบียนเรียกใช้ตัวแปรก่อนประกาศ (นักเรียนไม่เห็นงาน) · หน้าสรุปไม่ดึง `is_open` ตอนโหลดหน้า (สถานะขึ้นปิดรับทั้งที่เปิด)

- มหาวิทยาลัยที่ตั้งเป็น "สีสด" (หัวบัตรสว่าง): คำว่า Congratulations! เปลี่ยนจากทองไล่เฉดเป็น **ขาวครีม `#FFFDF5` ขอบทองบาง + เงาเข้ม** เพราะทองกลืนกับพื้นส้ม/แดง/ม่วงสด

### PR #54 — ปรับสีมหาวิทยาลัย + ตั้งค่า "สีสด"
- ไฟล์: `congrats-card-draw.js`
- ตาราง `__UNI` เพิ่มช่องที่ 4 `'v'` = สีสด (หัวบัตรใช้สีจริง ไม่ทำให้เข้มลง; ฟังก์ชัน `uniVivid(d)`; ไม่ใช้เมื่อมี `d.color`)
- ลาดกระบัง (KMITL) `#E35205` + สีสด — หัวบัตรส้มเหมือนตัวย่อ
- ธุรกิจบัณฑิตย์ (DPU) `#6B2D5C` → **`#8E24AA`** ม่วงสด + สีสด (ราชมงคลพระนคร/บ้านสมเด็จฯ ยังเป็น `#6B2D5C`)
- แม่ฟ้าหลวง (MFU) `#A6192E` → **`#E4002B`** แดงสด + สีสด
- ฐานข้อมูล/สิทธิ์: ไม่เปลี่ยน
